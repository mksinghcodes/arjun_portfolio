## 🌟 Key Features

- **Executive Profile & Identity**: Clean, modern circular portrait with verified credential badges and full career timeline across major UAE master developments.
- **Off-Canvas Left Navigation Menu**: Clean, spacious top navigation bar with a dedicated slide-in navigation drawer for all portfolio sections, tools, and direct channels.
- **Projects & Capital Works Tracker**: Filterable, paginated project management module with milestone tracking, budget utilization, and PDF project briefs.
- **Asset Register & Lifecycle Management**: Comprehensive asset database with criticality ratings, remaining useful life indicators, and scannable QR tags.
- **Maintenance & Work Orders**: Planned preventive maintenance (PPM) schedules, reactive ticket management, and an interactive FullCalendar view.
- **Interactive Analytics & Gantt Schedules**: Live KPIs, budget vs. spend charts, skill radar matrices, and milestone timelines.
- **Super Admin CMS Dashboard**: Role-based access control (Super Admin, Admin, Manager, Staff, Viewer) with full on-platform content editing, logo/branding customization, and audit logging.
- **Multi-Format Reporting & Exports**: Generate CVs and briefs in PDF, download structured registers in Excel (XLSX) and CSV, and backup/restore entire datasets in JSON.
- **Bilingual & Responsive**: Seamless English & Nepali (नेपाली) localization, high-contrast dark and light themes, and offline PWA capability.

## 🚀 Quick Start / Local Preview

This project is built as a self-contained, zero-dependency platform:

1. **Direct Browser Open**:
   Double-click `index.html` to open it immediately in any modern web browser (Chrome, Edge, Firefox, Safari).

2. **Local HTTP Server**:
   ```bash
   # Using Python 3
   python -m http.server 8080

   # Or using npx
   npx serve .
   ```
   Open `http://localhost:8080` in your browser.

---

## 🌐 Deploy to GitHub Pages

1. Go to your repository on GitHub: `https://github.com/mksinghcodes/arjun_portfolio`.
2. Click **Settings** > **Pages**.
3. Under **Branch**, select `main` branch and `/ (root)` folder.
4. Click **Save**.
5. Your live portfolio will be deployed automatically at: `https://mksinghcodes.github.io/arjun_portfolio/`.
